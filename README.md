# User Management API (Flask) 📝

Мой первый pet-проект на Flask. 
Простое REST API для управления пользователями с валидацией данных и документацией Swagger.

## Стек
- **Python**
- **Flask** — веб-фреймворк
- **Marshmallow** — валидация данных
- **Flasgger** — генерация Swagger документации
- **JSON** — хранение данных (вместо базы данных)

## Функционал (CRUD)
- **GET /users** — получить список всех пользователей.
- **GET /users/{id}** — получить пользователя по ID.
- **POST /users** — создать нового пользователя (с валидацией имени и email).
- **PUT /users/{id}** — обновить данные пользователя.
- **DELETE /users/{id}** — удалить пользователя.

## Особенности
- Валидация входящих данных через `marshmallow` (проверка на пустое имя, корректность email, уникальность email).
- Данные сохраняются в файл `users.json` (при перезапуске сервера не теряются).
- Встроенная интерактивная документация Swagger (доступна по адресу `/docs/`).
